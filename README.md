# Growify Digital — Website Redesign Prototype

A responsive static multi-page website concept created from the supplied Growify AI Generalist assignment and Growth Deck.

## Run locally
- Unzip the project.
- Open `index.html` in a browser. No build step or package installation is required.
- For a more realistic local server, run `python -m http.server 8000` from this folder and open `http://localhost:8000`.

## Pages
- `index.html` — homepage and enquiry form
- `services.html` — core service pages
- `case-studies.html` — two case-study narratives and future story pipeline
- `products.html` — Lookify, Rossify, Craftify and integrations
- `about.html` — company story and office-tour concept
- `styles.css` — responsive design system
- `script.js` — mobile menu, year and email-draft form behaviour

## Important before submission
1. Deploy to a public preview host (e.g. Vercel or Netlify) and test the live URL on desktop and mobile.
2. Replace the temporary Lookify link with its verified official URL.
3. Replace generic Unsplash editorial images with licensed/approved Growify or client assets if available.
4. Get written approval for all company and client claims, logos and case-study metrics. The case-study figures are transcribed from supplied materials and are explicitly flagged for verification.
5. Rossify and Craftify details are marked as unknown because the supplied materials do not describe their features.
6. The contact form uses `mailto:` to draft an email; it does not store or send data to a backend.
7. This is a prototype, not an authorised modification of growify.in.

## Design direction
Editorial luxury meets a practical growth operating system: warm neutral backgrounds, deep green, lime accents, serif contrast headlines, restrained motion and a connected customer-journey narrative.

## Accessibility and performance notes
- Semantic headings, labels and form fields.
- Keyboard-usable links and native controls.
- Mobile navigation toggle with `aria-expanded`.
- Reduced-motion preference respected.
- Images use external Unsplash URLs for this prototype; download/optimise approved assets locally before production.
- Add production analytics, form validation/server handling, sitemap.xml, robots.txt, structured data, redirects and Core Web Vitals checks before launch.
